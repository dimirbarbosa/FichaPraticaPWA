Perguntas Git e GitHub

  1. O que são operações de Commit, Push e Pop efetuadas num repositório?

    Resposta: Commit é a operação que grava as alterações efetuadas no repositório local. Push envia essas alterações para o repositório remoto. Pop recupera alterações previamente armazenadas através de um stash.

  2. Quais são as vantagens de usar Branchs num repositório Git?

    Resposta: As branches permitem desenvolver novas funcionalidades de forma isolada, sem afetar a versão principal do projeto, facilitando também o trabalho colaborativo.

  3. Nos Merges de conteúdos resultantes de um "Pop" podem resultar conflitos. Em que consistem e como podem ser resolvidos esses conflitos?

    Resposta: Os conflitos ocorrem quando existem alterações incompatíveis nas mesmas linhas de um ficheiro. Devem ser resolvidos manualmente pelo programador antes de concluir o merge.

  4. Clone e Fork são formas diferentes de replicar um repositório Git. Quais as diferenças entre eles?

    Resposta: Clone cria uma cópia local de um repositório no computador. Fork cria uma cópia do repositório na conta GitHub do utilizador, mantendo a ligação ao projeto original.
